# Offline ARMv7 AOT performance attribution decision

Decision: **`SELECTIVE_OFFLINE_AOT_ROUTE_SUPPORTED`** for continued offline compiler investment. This is an architecture validation on the two locked real workloads, not a claim that all games benefit or that the experimental batch handoff is production ready. The existing full KungFoo indexed route remains a negative result (`0.427×` interpreter); full-library AOT is not authorized by this decision.

## L0–L7 causal result

- **L0/L1:** Same-state real-segment replay passed architectural state, PC, instruction count and guest-page hash on both games. KungFoo's 237-instruction segment measured 3,840 ns interpreter, 576 ns generated C, 356 ns indexed region, 169 ns guardless region, and 104 ns scalar lowering per repetition (five interleaved samples; medians). Gloomy's 10-instruction selected segment measured 213, 65, 65, 54 and 48 ns respectively. These are isolated payload comparisons, never substituted for integrated-route timing.
- **L2 and final machine code:** Indexed KungFoo region 593 has 2,957 host instructions, 216 guest-register-array stack accesses and 53 CPSR stack accesses. The scalar *selected segment* has 199 host instructions, eight stack save/restore accesses, and zero guest-array or CPSR stack accesses. Gloomy indexed region 0 has 2,427 host instructions, 256 guest-array and 47 CPSR stack accesses; its scalar selected segment has 83 host instructions and zero guest-array/CPSR stack accesses. Therefore current indexed C representation is `HOST_REGISTER_RESIDENCY_INEFFECTIVE`; test-only scalar lowering is `HOST_REGISTER_RESIDENCY_EFFECTIVE`. These whole-region and selected-segment counts have different coverage and must not be compared as per-instruction code-size ratios.
- **L3:** KungFoo's selected path has 114 NZCV producer events; 57 are fully dead before use, 57 live, and 57 conditional consumers. Gloomy's selected path has one live producer. The current integrated indexed route has not incorporated scalar/lazy-flag lowering, so those liveness counts describe remaining compiler headroom, not measured full-route savings.
- **L4:** The selected KungFoo segment performs 61 real guest-memory operations. Both scalar and indexed versions execute and verify the same guest-memory effects. The 65 ns guardless-to-scalar median difference contains state representation, address handling and lowering effects together; there is no defensible independent guest-memory-framework nanosecond estimate from these runs. The final route result does not depend on attributing that difference to guest memory.
- **L5:** Controlled guard/accounting variants passed same-state replay. For the KungFoo selected CFG, guardless main symbol has 188 host instructions; guard-only 338, accounting-only 266 and both 452. Timing differences at this scale were noisy. The guard-once correction passed correctness but gave no stable gain (KungFoo combined median 333.0 ns versus guard-once 339.8 ns); it is not part of the selected route.
- **L6:** The first selective full route lost because one lookup miss forced one interpreter instruction and outer-driver re-entry. The test-only batch handoff reduced KungFoo top-one lookup misses from 21,550 to 742 and raised the route from `0.161×` to `0.985×` without changing compiled coverage. With two hot regions, 3,171 compiled blocks include 2,686 directly chained blocks, and 759 drive calls are recorded in performance sample 1.
- **L7:** KungFoo top-two median component samples show AOT drive 87/75 µs and fallback interpreter 428/368 µs in the two jobs; SVC interpreter is 0–1 µs. Boundary time is recorded separately (median 1,052/907 µs) and excluded from both guest-engine speed ratios. Gloomy warm records zero fallback; median warm AOT engine is 46.418 ms versus interpreter 58.567 ms.

## Route boundary

The cross-game result supports a general **interpreter baseline plus bounded, profile-selected ELF regions**. The selection rule is executable and game-agnostic: rank discovered regions by observed dynamic instruction count, compile the top two when present, and leave other instructions to the interpreter. Gloomy's fixed trace has one observed region and therefore selects one. KungFoo's top-one configuration does not win; top-two improvement is modest and noisy (10/14 paired wins across two jobs). A production compiler must retain a conservative profitability gate and interpreter fallback; this evidence does not authorize blanket translation, product readiness, or a change to D004/D005/D011 or Android-visible ownership.

The experimental `AGR_AOT_SELECTIVE_BATCH` handoff is isolated to these AOT validation workflows. Its measured result establishes that the dominant one-instruction miss cost can be removed while maintaining the guest contract. The scalar proof establishes that further register-resident lowering is feasible but is not credited as an integrated-route speedup.
