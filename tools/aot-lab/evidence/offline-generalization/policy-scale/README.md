# Fast-only static policy scale

All four sources in this directory were generated by `translate_offline.py` at commit `485b775c0dc89aaac9b69d6e7c89eb3b5f2d16d0`, using the same original KungFoo ARMv7 ELF recorded in `../run-36373038682/input-armv7.so`, its formal test load bias `0x10000`, and no execution trace. Each manifest records the SHA-256 of its corresponding generated C file. Diagnostic functions were disabled for an equal-size comparison. `summary.json` verifies identities and collects preparation times, discovered PC/modes, block counts, and source sizes.

These are preparation and source-size measurements on one ELF. Only the `abi` and `all-exidx-sweep` policies have separate real execution results in this repository. The intermediate policies cannot be assigned dynamic coverage or runtime performance from this directory. Build/object size and execution cost for `all-exidx-sweep` are measured separately by the fast-only simulator job.
