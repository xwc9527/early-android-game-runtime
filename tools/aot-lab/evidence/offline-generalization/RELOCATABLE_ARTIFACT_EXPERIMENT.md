# Relocatable offline AOT artifact experiment

Run `36403473005` tested commit `cd447740af8637a5e0c56607f3600d2fc8c1bdf3` and tree `6d6493d4a02f6168ad78b898d40fce09ff18000a`. The original artifact ZIP and all 42 byte-verified extracted members are in `run-36403473005/`. Input ELF SHA-256 was `2b8672e79da33de4661f6aa0bcb79df2a302637aca9829d53fff8077a6895638`. Translation used public ELF symbols, code, and init/fini metadata, with no execution trace or fixed load bias. The generated C SHA-256 was `feb0c74658295fecf7f3552c8c06b0835fb0fad45c133e5ab0c3c0425ee17fd5` for both executions. The runtime supplied the formal linker result as a distinct execution input; the run's manifest erroneously lists that runtime value among translation inputs, corrected in the next source commit without altering these original files.

The same compiled artifact executed at load biases `0x02800000` and `0x00010000`. At each bias, the interpreter executed 174 instructions; AOT executed 153, and SVC interpreter executed 21. There were zero ordinary AOT misses, 32 matched PC/CPSR/register checkpoints, complete accounting, equal host calls, and equal checked renderer/framebuffer results. Both differentials report `semantic_pass: true`. This proves load-address independence for this single ELF renderer path. It does not prove multi-library dispatch, dynamic `dlopen` binding, or broad native workload coverage.

The artifact generated 465,145 C bytes and 165,560 ARM64 `__text` bytes from a 9,376-byte ELF; compile wall time was 1.50 seconds. The result's elapsed time includes graphics/runtime boundaries and has no paired guest-engine measurement, so it does not support a performance claim for the relocation mechanism. The broader KungFoo execution path is the next check.

Run `36404893556` tested the linker-bound version at commit `e0166e2`. Its original ZIP and all 42 extracted members are in `run-36404893556/`, with byte identity verified. The generated C SHA-256 was `f24ce98200d6176f7e644ee1cfdfee527a664498f44cc51de387f30a7a6355a7`. The manifest now explicitly separates static translation inputs (`ELF32 ARM code`, dynamic symbols, init/fini arrays) from the runtime formal linker load bias. The AOT artifact's ELF identity is checked when the AOSP linker maps the source, before constructors execute; the App no longer sets the bias manually. Both the fixed `0x02800000` and first-fit `0x00010000` executions again passed 174-instruction interpreter/AOT differentials with 153 AOT, 21 SVC, no ordinary fallback, and 32 matching checkpoints. This closes automatic binding for this one ELF across two addresses. It does not close multi-artifact selection or concurrent native libraries.

Run `36405016519` applied that same generic mechanism to the larger original KungFoo ARMv7 ELF and bounded pre-thread-creation path. The original ZIP and all 90 byte-verified extracted members are in `run-36405016519/`. The artifact was prepared from ELF code, symbols, init/fini, and EHABI, without an execution trace or fixed load bias; its generated C SHA-256 is `6e5d431d8f3556ba93199558c120d528210ef4867d24243b7107aeef35c00ca5`. Of 29,703 checked instructions, 26,404 executed in AOT and 3,299 in interpreter. The 125-instruction path withheld from translation contained 117 AOT and 8 SVC instructions. All 6,632 fast checkpoints, host calls, checked observables, and instruction/fallback accounting passed. Seven paired guest-engine medians were interpreter 0.510 ms and AOT route 1.041 ms, a 0.490 speed ratio. Generated C was 18,316,808 bytes, ARM64 `__text` 5,404,896 bytes, and compiler wall time 82.40 seconds. This preserves correctness and coverage at a runtime-selected bias but retains the performance regression of the current implementation.

The reproducible `classify_offline_fallbacks.py` analysis of that run's 2,006 `lookup_miss` events found 1,520 statically decodable instructions outside the EHABI/direct-CFG closure, 192 events at four indirect mode-switch targets that a Thumb-biased sweep missed, and 294 unsupported atomic instructions (`LDREX` 147, `STREX` 147). These are public discovery, mode handling, and ARM atomic capabilities; the evidence does not point to a game-identity condition. The separate 629 IT-state and 664 SVC events remain in the raw differential.

Run `36407011220` used the same `all-exidx` public entry policy as KungFoo on the original Gloomy ELF. Its original ZIP and 42 byte-verified members are in `run-36407011220/`. The generated artifact SHA-256 was `3db331b5cf8e91a7bb3e518569461e507a6264c063ae8c09d6c5452f37273c0e`, with 308 fast blocks, 476,083 C bytes, and 0.024-second offline preparation.
