# API19 libcore integer boxing cluster

The validated Migration Books for Frozen Bubble, Gloomy Dungeons 2, and Vector Pinball contain five observed entries in this semantic owner: `valueOf(int)`, `intValue()`, `longValue()`, `floatValue()`, and `equals(Object)`. The reproducible cross-game cluster seed is in `tools/reference-lab/evidence/integer-boxing-source-seed.json`: eight game-entry observations totaling 41,776 calls. `intValue()` alone accounts for 29,815. These counts prioritize source review; they do not limit the cluster to the values or methods those games used.

The semantic owner is `platform/libcore@9b24ebf95f897a75c60c9c68d00694406afa6fbc`, `luni/src/main/java/java/lang/Integer.java` (SHA-256 `5aae098f5c2fd832bd739fead6f04586ccbb98e6606c22ede64001ae573420a3`). `Integer.valueOf(int)` at line 705 returns the shared `SMALL_VALUES[i + 128]` for `-128 <= i < 128` and constructs a new `Integer` outside that interval. The static initializer at lines 712-718 constructs the 256 cached objects. The `Integer(int)` constructor at line 88 stores `value`; `intValue()` at line 311 returns it. `Number.Number()` is the superclass constructor in `Number.java` (SHA-256 `ccbc3f77f43e7089cf715c2a40d99d6eecba675071e8b987865619f5f4c0c0b6`). The cluster is boxing, cached identity, initialization, and lifetime together, not a single `valueOf` replacement.

The cross-cluster VM owner is `platform/dalvik@36e356c96640775f0a3f167bd2426ea0f0093b8b`: `vm/oo/Class.cpp:dvmInitClass` runs superclass initialization, initializes static fields, and invokes `<clinit>`; `vm/alloc/Alloc.cpp:dvmAllocObject` allocates initialized-class instances; `vm/alloc/MarkSweep.cpp:scanStaticFields` keeps the `SMALL_VALUES` array reachable. A source port must preserve these class and GC contracts or explicitly depend on a separately closed Dalvik cluster.

The current AGR counterpart in `Runtime/DexLoom/AndroidMini/dx_android_framework.c` allocates a fresh boxed object on every `Integer.valueOf` call. `Runtime/DexLoom/VM/dx_vm.c` has static-field GC root scanning but registers a synthetic `Integer` class as already initialized. This is a source-backed difference, not yet a measured API19-to-AGR differential. No production change is authorized while class initialization, static-field identity, and GC integration remain unclosed.

All five seed entries and their cluster remain `SOURCE_LOCATED`; `MIGRATION_AUTHORIZED` is false. Next is closure of the Dalvik contracts and the full boxing cluster Source Manifest. Only then can the source-owned implementation replace the synthetic boxing path and enter a focused CLEAN differential.
