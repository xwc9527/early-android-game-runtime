# Governance history

Files in this directory are retained evidence. They are not active governance and they are not production migration input.

Active tools must not load these files when deciding a Framework owner, a reopen, or the next implementation.

- `java-public-owner.json` and `java-legacy-migration.json` are the retired pre-declared Framework migration surface.
- `reopens-pre-reference.json` holds Frozen Bubble, traversal, physical-first-frame, and DEX-parser reopens.
- `reopens-phase3-closed.json` holds closed Phase 3A and Phase 3C reopens.
- `expensive-run-plan-pre-reference.json` is the retired Frozen Bubble gameplay plan.

Later Framework owners come only from Migration Book → API19 Source Closure → Cluster Source Manifest. See `REFERENCE_MIGRATION_RULES.md`.
